# TIL | 데이터 사이언스 · AI 포트폴리오

> 배우고, 정리하고, 직접 만들어 보며 데이터 사이언스와 AI 역량을 쌓아가는 학습 포트폴리오입니다.

## About

데이터를 이해하고 문제를 해결하는 과정을 기록합니다.
단순한 학습 로그에 그치지 않고, 배운 내용을 다시 설명할 수 있는 지식 문서와 직접 구현한 프로젝트로 발전시키는 것을 목표로 합니다.

## Learning Roadmap

| 단계 | 학습 트랙 | 주요 주제 | 상태 |
|---|---|---|---|
| Step 1 | 데이터 분석 기본기 | Python · SQL · 통계 · EDA · ML 기초 | 진행 예정 |
| Step 2 | 산업별 데이터 분석 & ML | SQL · A/B 테스트 · AARRR · ML · Tableau · 텍스트 분석 | 진행 예정 |
| Step 3 | AI 기반 데이터 분석 서비스 | Computer Vision · 텍스트 분석 · RAG · 추천 시스템 · AI Agent · MLOps · 빅데이터 | 진행 예정 |

자세한 계획은 [로드맵](roadmap.md)에서 확인할 수 있습니다.

## How I Learn

1. 개념을 이해하고
2. 작은 예제로 직접 확인하고
3. 시행착오를 기록하고
4. 프로젝트에 적용한 뒤
5. 다른 사람이 읽어도 이해할 수 있도록 다시 정리합니다.
