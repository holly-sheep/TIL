# TIL

> Today I Learned — 오늘 배운 내용을 기록하는 저장소입니다.

## 목적

- 배운 내용을 짧게 정리하고 오래 기억하기
- 나중에 다시 찾아볼 수 있는 개인 학습 기록 만들기
- 꾸준히 공부하고 기록하는 습관 만들기

## 기록 방법

1. 날짜별 폴더를 만듭니다.
2. 주제에 맞는 Markdown 파일을 추가합니다.
3. `template.md`를 복사해 배운 내용을 정리합니다.
4. 이해한 내용을 자신의 말로 기록합니다.

## 폴더 구조

```text
TIL/
├── README.md
├── template.md
└── 2026-08-05/
    └── git-github.md
```

## 기록 목록

- 기록이 추가되면 여기에 주제와 링크를 정리합니다.

## 작성 원칙

- 짧더라도 꾸준히 기록합니다.
- 단순 복사보다 직접 이해한 말로 정리합니다.
- 예제 코드와 시행착오를 함께 남깁니다.
- 모르는 점과 다음에 공부할 내용도 기록합니다.
